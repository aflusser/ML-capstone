# ML Problem Capstone

A capstone assignment demonstrating the machine learning lifecycle on an Airbnb NYC listing prediction problem. The project includes data exploration, feature engineering, model selection, and model evaluation.

## Overview
Built an end-to-end predictive pipeline in Jupyter notebooks to model Airbnb listing price outcomes using exploratory data analysis, feature engineering, and supervised learning (logistic regression and neural network).

Performed cross-validation and hyperparameter tuning with scikit-learn and TensorFlow/Keras, and evaluated models using Accuracy and F1 scores, with visualizations for interpretability.

## Features
- Logistic Regression baseline
- Data exploration & visualization
- Feature engineering and model selection
- Hyperparameter tuning with GridSearchCV
- Binary classification pipeline
- Cross-validation and model evaluation
- Accuracy and F1 score metrics

## Dataset
This project uses the InsideAirbnb dataset for New York City (December 2021).

Source: https://insideairbnb.com/get-the-data/

## Technologies
- Python
- Jupyter Notebooks
- scikit-learn (Logistic Regression, GridSearchCV)
- TensorFlow/Keras (Neural Network)
- pandas, NumPy
- Matplotlib, Seaborn
